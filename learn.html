Links, images & file paths

Four short sections. After each one, try it in the live playground at the bottom and tick the box when it makes sense.

1 · Links with <a>

The anchor tag <a> makes a link. Its href attribute (short for hypertext reference) says where the link goes. The text between the opening and closing tag is what people click.

<a href="about.html">About me</a>
You want to…Write this
Go to another page on your site<a href="about.html">About</a>
Go to another website<a href="https://developer.mozilla.org">MDN</a>
Open the link in a new tab<a href="https://github.com" target="_blank">GitHub</a>
Jump to a section on the same page<a href="#contact">Contact</a> goes to the element with id="contact"
Start an email<a href="mailto:me@example.com">Email me</a>
Write link text that makes sense on its own, like “See my projects”. Avoid “click here”: screen reader users often jump from link to link and only hear the link text.

2 · Images with <img>

<img> is a void element, so it has no closing tag. It needs two attributes:

  • src: the path to the image file.
  • alt: a short description of the image. Screen readers read it out loud, and the browser shows it if the image can't load.
<img src="img/sample-photo.svg" alt="Mountains under an orange sun" width="400" height="240">

width and height are optional, but they let the browser save space for the image before it loads, so the page doesn't jump around.

If an image is only decoration, use an empty alt: alt="". Screen readers then skip it. Leaving out alt completely is different: some screen readers read the file name out loud instead.

To make an image clickable, put it inside a link:

<a href="index.html"><img src="img/logo.svg" alt="Path Finder home"></a>

3 · File paths

A path tells the browser how to get from the file you're writing in to the file you want. Picture this site:

my-site/ ├── index.html ├── about.html ├── styles.css ├── img/ │ └── logo.png └── pages/ └── contact.html
Kind of pathExampleMeaning
Absolute URLhttps://github.comA full web address. Use it for other websites.
Same folderabout.htmlFrom index.html, the file is right next to you.
Down into a folderimg/logo.pngFrom index.html: open img, then find logo.png.
Up a folder../index.htmlFrom pages/contact.html: .. means “the folder above me”.
Up, then down../img/logo.pngFrom pages/contact.html: go up to my-site, then into img.

Paths that don't start with / or https:// are relative: they always start from the folder that contains the current file. Every ../ goes up one level, so ../../ goes up two.

Watch out for leading slashes. /img/logo.png starts at the root of the domain. On a GitHub Pages project site like you.github.io/bmis235-html-4/, the root is you.github.io/, so the image isn't found. Plain relative paths work everywhere.
